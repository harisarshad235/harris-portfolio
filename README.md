### Optional analytics

Set `NEXT_PUBLIC_GA_ID` in the hosting provider environment to enable Google Analytics. Leave it unset to keep analytics disabled.

The homepage uses the Netlify `URL` build variable for canonical and social-sharing URLs. If deploying elsewhere, set `NEXT_PUBLIC_SITE_URL` to the site's public origin (for example, `https://your-domain.example`) so those URLs are generated correctly.
