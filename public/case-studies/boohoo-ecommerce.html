The engagement

A consistent returns experience across brands

Boohoo Group needed a dedicated returns service that could support its brand portfolio while connecting to the systems used to fulfil and track customer orders. The work brought return activity into a more unified operational flow.

As a Junior Project Coordinator at SOFTOO, I supported weekly delivery meetings and kept project documentation current so business and technical stakeholders could track milestones and release progress.

Platform technologies

  • AWS Lambda and Amazon RDS
  • Amazon SQS and SNS
  • Order and SKU-level integration
  • Warehouse management connection

01 / The challenge

Connecting many moving parts

Multiple brands

A single returns capability had to work across distinct storefronts and operating needs within the group.

Complex system handoffs

Returns depend on accurate order and item details, with information moving between customer-facing services and warehouse operations.

Flexible delivery capacity

The programme needed experienced engineering and clear coordination to bring a bespoke service into operation.

02 / The delivery

Joining the returns journey end to end

01

Use a managed cloud foundation

Build on AWS serverless components and managed data services to support a flexible service footprint.

02

Connect operational systems

Carry relevant order and SKU information through the returns process and into warehouse workflows.

03

Coordinate across workstreams

Maintain shared delivery checkpoints and clear documentation across stakeholder and engineering teams.

03 / Project impact

A reusable capability for a growing brand group

The project created a returns workflow designed to serve multiple Boohoo Group brands, linking customer operations with order and warehouse information through a tailored platform. Its serverless foundation supported operational efficiency, simpler integrations, and expansion across the group.
