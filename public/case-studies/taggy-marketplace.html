The engagement

Keeping marketplace delivery connected

Taggy presents itself as a fashion-resale marketplace where people can browse listings or sell items. The product advertises discovery features such as image search, auto-tagging, and suggested pricing, as well as an optional listing service and courier delivery.

As Project Manager at Sigma Digital Solutions, I coordinated client communication, task ownership, sprint progress, and deadlines using Trello. I also prepared user manuals to support handover and end-user adoption.

Delivery focus

  • Client communication
  • Trello work tracking
  • Parallel sprint coordination
  • User documentation

01 / The challenge

Maintaining a shared view across streams

Marketplace journeys

Browsing, creating a listing, discovering items, and arranging delivery all need to fit into a clear resale experience.

Concurrent delivery tasks

Multiple workstreams create dependencies that can be missed when ownership, priorities, and deadlines are not easy to see.

Adoption beyond release

Successful handover requires usable documentation so people can understand and use the delivered product.

02 / My contribution

03 / Project impact

Clearer coordination through delivery and handover

Structured sprint tracking created a clearer view of parallel work and upcoming commitments, while user documentation supported handover and adoption. Image search, auto-tagging, suggested pricing, listing assistance, and courier services are features advertised by Taggy.
